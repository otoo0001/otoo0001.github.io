# Nicole Gyakowah Otoo, academic website

This is a static website prepared for GitHub Pages.

## Edit the content

Open `content.js`. Publications, conference presentations, experience entries, blog posts and the GitHub profile link are kept together in that file. Save and commit the change. GitHub Pages republishes automatically.

## Publish with GitHub Pages

1. Create a public GitHub repository named `otoo0001.github.io`.
2. Upload all files and folders from this package to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, and `/root`.
4. The website will be available at `https://otoo0001.github.io/`.

For a project repository instead, enable Pages in the same way and use its generated project URL.
